# PostgreSQL 18 — Sqitch + pgTAP Development

Database development project for **PostgreSQL 18**, built around a
[Sqitch](https://sqitch.org/) + [pgTAP](https://pgtap.org/) (`pg_prove`) + Git
workflow: every schema change is a versioned, reversible Sqitch change with a
matching pgTAP test.

## Repository layout

```
deploy/       Sqitch deploy scripts (forward migrations / DDL)
revert/       Sqitch revert scripts (exact inverses of deploy)
verify/       Sqitch verify scripts (post-deploy assertions)
test/         pgTAP tests, executed with pg_prove
sqitch.plan   Ordered list of changes (generated by Sqitch — tracked in git)
sqitch.conf   Sqitch configuration
```

## Prerequisites

- PostgreSQL 18 — `brew install postgresql@18`
- Sqitch with PostgreSQL support
- pgTAP extension + `pg_prove`
- Perl (5.8+) with `TAP::Parser` (bundled with Perl)

## Getting started

```sh
# 1. Install the toolchain (macOS / Homebrew)
brew install postgresql@18

# 2. Install Sqitch (see below) and pgTAP, then initialize the project
sqitch init pg --top-dir .
sqitch add appschema -n "Add application schema"

# 3. Run migrations and tests against a scratch database
createdb mydb
sqitch deploy db:pg:mydb
pg_prove -d mydb test/*.sql
```

## Workflow

1. **Add a change** — `sqitch add <name> --require <parent> -n "<note>"`
2. **Author** `deploy/<name>.sql` (idempotent DDL), `revert/<name>.sql`
   (exact inverse), `verify/<name>.sql` (loud assertions).
3. **Test** — write a pgTAP test in `test/` for the change.
4. **Deploy & verify** — `sqitch deploy --verify db:pg:<db>`.
5. **Commit** — deploy/revert/verify + test land in one atomic git commit.
6. **Tag releases** — `sqitch tag v1.0.0` at release points.

See the project skills for detailed authoring and validation conventions.
